<h1 align="center">Python Flask Auth + SQLAlchemy</h1>

**Description**: Learning Python w/ Flask + SQL Alchemy + auth workflow.

**Stack**:

- Flask;
- Flask-SQLAlchemy;
- Flask-Login;
- Werkzeug;

## Getting started

Follow step by step below to execute this project correctly:

```SH
# create venv
python3 -m venv .venv
source .venv/bin/activate # always use this command to activate venv (per terminal session)

# install dependencies
pip3 install -r requirements.txt

# run flask server
flask run
```
